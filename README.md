Uma aplicação web completa desenvolvida com Java e Spring Boot, utilizando Thymeleaf para a interface do usuário e JWT (JSON Web Tokens) para autenticação segura. O sistema conta com um CRUD completo integrado a um banco de dados.
 Tecnologias Utilizadas :
. Java 25
. Spring Boot 
. Spring Security (Autenticação JWT)
. Spring Data JPA
. Thymeleaf
. MySQL 
. Maven 

  FuncionalidadesAutenticação Segura:

. Login e registro de usuários com geração de tokens JWT.
. CRUD Completo: Criação, leitura, atualização e exclusão de registros (Ex: Produtos,Clientes) 
. Páginas Dinâmicas: Interface amigável renderizada pelo Thymeleaf.
. Segurança de Rotas: Controle de acesso baseado em perfis de usuário (Roles).
